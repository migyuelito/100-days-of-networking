# Sources and attribution

## Primary course

**Jeremy's IT Lab — Free CCNA 200-301 Complete Course** by Jeremy McDowell

- Lessons: [YouTube playlist](https://www.youtube.com/playlist?list=PLxbwE86jKRgMpuZuLBivzlM8s2Dk5lXBQ)
- Lab files and flashcards: the link in the top line of each video description
- Website: [jeremysitlab.com](https://www.jeremysitlab.com/)

I follow the lecture and guided lab, then rebuild, change, and test the work on my own. Each daily entry names the lesson it used.

## What this repo contains

- My own rebuild files (`.pkt`), device configurations, notes, test evidence, and write-ups
- No course lab files, flashcards, slides, or videos. Guided days link to the lesson instead of copying it.

## How entries label the work

| Label | Meaning |
|---|---|
| **Guided** | Followed the course lab as instructed |
| **Rebuilt** | Built it again from a blank file, without the video or solution |
| **Changed** | Added or changed a requirement that the course lab didn't include |
| **Diagnosed** | Found and fixed a fault, whether I planted it or someone else did |
| **Original** | My own scenario, with no course lab behind it |
