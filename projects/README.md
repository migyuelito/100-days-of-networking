## 🗂️ Folder Layout

```
projects/<project-name>/
├── README.md      ← employer-facing summary (templates/project-summary.md)
├── report.md      ← technical report (templates/technical-report.md)
├── topology.png
├── configs/       ← final device configs, credentials removed
└── evidence/      ← test outputs and screenshots, numbered in test order
```

Start each project from the templates: [project-summary.md](../templates/project-summary.md) for the summary and [technical-report.md](../templates/technical-report.md) for the report.
